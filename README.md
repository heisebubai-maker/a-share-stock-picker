# A股研究台 · 行情选股与持仓复盘

## 每天怎么用

1. 点击首页“一键更新行情与复盘”：后台更新观察池、持仓股票、上证指数、沪深300和创业板指数，完成后自动保存当日研究快照。
2. 看“今日市场判断”和“下一步计划”：优先处理持仓缺数据、风险线、仓位超限，再考虑新候选。
3. 看“重点候选观察”：按分数、趋势、成交额和ST/停牌过滤，已持有股票不再作为新候选；已知PE≤0的股票不进入候选，每行业最多2只，最多5只。展示筛选依据、PE/PB、观察区、失效线和条件式计划。
4. 在“我的持仓”录入代码、成本、股数、短线/中长期周期与持有逻辑。保存同代码会替换当前仓位，不累计成交。随后一键更新会自动纳入持仓。
5. 展开“账户与风险参数”填写可用现金与仓位/风险阈值。默认参数是研究示例，不是针对个人风险承受能力的配置。

**候选不等于已验证的基本面优质股。** 当前能核对行情、趋势、流动性、日线PE/PB和行业快照；未核查盈利质量、财务真实性、新闻或公告。持仓复盘解释价格变化与规则触发，不能编造涨跌原因。

行情、成本或现金不足时显示缺失，不用模拟价格估算真实持仓。首页可直接查看缓存，技术因子和原笔记工具移到折叠设置里。

## 计划规则与持仓复盘

- 市场环境按覆盖指数是否高于20期均线分为偏强/分化/偏弱；不足2个有效指数时不形成新增股数。行业强弱仅是股票池内行业等权涨跌，不代表全行业资金流。
- 新候选需评分≥65且收盘高于20期均线，观察区为最近收盘±1%，失效线由近20期最低收盘和风险幅度推导，非委托价格或收益目标。
- 新增股数上限取现金、单只仓位、剩余总仓位和单笔风险预算的最小值，按100股向下估算。每只上限独立计算，不能将多只上限相加执行；板块特殊申报规则需另核实。
- 缓存超过4个自然日、缺指数、环境偏弱、持仓价格缺失或仓位已超限时，新候选只保留观察，股数上限为0。四个自然日是保守提示阈值，长假可能误触发，非交易日历判断。
- 持仓盈亏=(收盘−成本)×数量；仓位以已录入持仓市值+现金估算。缺一只价格则账户总额与仓位显示待补齐。不含费用、分红和已实现收益。
- 短线/波段以20期均线复核，中长期以60期均线复核；成本风险线=成本×(1−设置幅度)。停牌、ST、触及风险线、趋势转弱分别显示行动条件，不执行下单。
- 复盘保存当时的持仓、参数、行情与规则输出，之后编辑持仓不改变旧快照。同日再次保存会替换该日研究快照；原因子快照和笔记仍保留。
- 目前是当前持仓快照复盘，不重建历史成交、可卖数量或T+1。近期除权除息可能扭曲不复权价格，计划必须人工复核。

新增接口：`GET /api/dashboard`，`GET/PUT /api/holdings`，`DELETE /api/holdings/{code}`，`GET/PUT /api/preferences`，`POST /api/update`（后台任务），`GET /api/update-status`，`GET/POST /api/research-reports`，`GET /api/research-reports/{day}`。

标准Windows启动脚本现在会检查服务就绪后自动打开浏览器；失败时显示日志，日志在本机 `data/service.log`，不上传仓库。持仓、账户参数和报告保存在本机SQLite，不上传GitHub。同步行情会向BaoStock发送需查询的股票代码及日期，不发送成本、股数或现金。

Windows 本地网页版，FastAPI + SQLite + 原生 HTML/CSS/JavaScript，无需 Node.js、Docker 或行情密钥。默认使用 BaoStock 沪深 A 股日线接口，支持自选股票池同步、可解释规则评分、每日复盘和持久化笔记。

**真实数据需先同步。** 首次进入页面点击“一键更新行情与复盘”，默认12只沪深股票仅用于研究起点，不是全市场排名；可以输入1至50只六位代码（含自动纳入的持仓）。获取最近180天、截止北京时间昨天的日线，不含盘中行情。同步时需联网，查询失败不切换模拟数据。无自动下单、无盈利承诺，不构成投资建议。

## Windows 启动

1. 安装 Python 3.12（勾选 Python Launcher 和 pip）。
2. 下载或克隆本仓库，双击 `start.bat`。首次启动需要联网安装依赖。
3. 浏览器自动打开 <http://127.0.0.1:8000>。点击一键更新，录入持仓与现金，查看市场、候选和下一步计划。研究池设置在折叠面板中。
4. 在启动窗口按 Ctrl+C 停止。再次启动会保留笔记。

也可在项目目录手动执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

端口冲突时改为 `--port 8001` 并访问对应地址。依赖下载失败时检查网络和 pip 镜像。若 `.venv` 创建中断，可将其重命名后重新启动。该服务面向本机单用户，无登录认证，请保持绑定 127.0.0.1。

## 评分与复盘

策略版本 `trend-v1`：评分使用所选日期及之前的数据，至少21期收盘价。

| 因子 | 公式（clip 限制到 0–1） | 上限 |
|---|---|---:|
| 20期动量 | 40 × clip((20期涨跌百分数 + 10) / 20) | 40 |
| 均线趋势 | 30 × clip((收盘相对20期均价的偏离百分数 + 5) / 10) | 30 |
| 稳定性 | 20 × clip(1 − 20期日收益率总体标准差百分数 / 5) | 20 |
| 流动性 | 10 × clip(20期平均成交额 / 5亿元) | 10 |

排除最新状态为 ST、停牌的样本；20期平均成交额低于1亿元、收盘价非正或非有限值、历史不足也排除。每项四舍五入后求和，同分按代码排序。阈值是演示启发式，未经回测优化，分数不代表买卖建议。

复盘保存当日全部合格股票及因子快照，以来源、日期、策略版本作为唯一键。重复生成更新快照并保留人工笔记。数据默认保存在 `data/stock.sqlite3`；停止服务后备份该文件即可。数据库和 `.env` 不提交 Git。

## 真实行情与缓存

- 数据源：[BaoStock](https://pypi.org/project/baostock/)，匿名会话。SDK独立进程运行，每次最长90秒，失败自动再试一次；失败提示可见，原缓存保留。
- 日线字段：收盘价、成交额（元）、ST与停牌状态。**不复权**（adjustflag=3）；除权除息可能产生价格跳变并扭曲评分，目前不能据此评价策略收益。
- 股票名称为当前基础资料，历史名称不是时点快照；输入池有人工选择偏差，不应用于严肃历史回测。仅支持沪深A股，不含北交所、基金或指数。
- 完整校验后在单个事务中替换该来源缓存，当前缓存恰好对应本次股票池与日期范围。部分代码无数据、无效字段或中断时整批不写入，不展示部分成功为完整市场。
- 页面显示最新缓存日期、距今天的自然日数、最近成功同步时间，以及所选日期的缺失股票数。自然日差可能包含周末节假日，不代表交易日延迟。最新日期以接口实际返回为准，不假设昨天有交易。
- 重启不联网、不自动下载；可离线查看已缓存结果。同步不会删除旧复盘和笔记，但历史复盘不会自动按新行情重算，需主动生成更新。
- 每次同步替换股票池，最多50只；手工点击同步，无定时任务。推荐只运行一个 Uvicorn 进程，本地同步锁不覆盖多个服务器进程。

## 文件与 API

- `app/main.py`：服务、输入校验、日期筛选、复盘和笔记 API。
- `app/storage.py`：SQLite 表和事务；`app/providers.py`：数据源协议与模拟实现。
- `app/strategy.py`：可解释评分；`app/static/`：中文响应式网页。
- `app/market.py`、`market_worker.py`：代码与行情校验、限时重试、BaoStock SDK适配。
- `tests/test_system.py`：接口、过滤、未来数据隔离与持久化测试。
- `docs/OPEN_SOURCE_REVIEW.md`：开源审查及选型；`docs/VALIDATION.md`：验证记录。
- `start.bat`、`requirements.txt`：Windows 启动与依赖；原有 `.github/workflows/` 运行 Windows 测试。

交互 API 文档：<http://127.0.0.1:8000/docs>。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/health` | 服务与数据库状态 |
| GET | `/api/data-status` | 来源、缓存日期、同步时间及默认股票池 |
| POST | `/api/sync` | 同步真实日线；JSON示例见下 |
| GET | `/api/dates` | 可选样本日期 |
| GET | `/api/screen?day=2026-10-16&limit=10` | 评分及因子 |
| POST / GET | `/api/reviews/2026-10-16` | 生成 / 读取复盘 |
| PUT | `/api/reviews/2026-10-16/notes` | 保存 `{"notes":"观察记录"}` |

测试：`.\.venv\Scripts\python.exe -m pytest -q`。

同步请求示例：`{"codes":["600519","000001"]}`；也可以指定 `start`、`end`（ISO日期）。每次1–50只，日期跨度不超过370天，结束日期早于北京时间今天。验证失败422，重复并发同步409，数据源失败502；不会覆盖成功缓存。网页默认180天。

## 数据源扩展与限制

环境变量 `STOCK_DB` 可指定数据库路径；`STOCK_SOURCE` 默认 `baostock`。设置为 `demo` 可运行原模拟演示（12个虚构样本、70个工作日，固定截止2026-10-16，不是真实交易日历）；模拟与真实数据按来源隔离，旧笔记保留。未知来源明确报错，不静默回退。当前仅一个真实来源，没有多源回退。

当前不含 LLM、机器学习训练、全市场扫描、实时行情、独立交易日历、复权、财务报表质量核验、回测、手续费、涨跌停和可成交性模拟、定时任务或消息推送。后续应先完成数据质量和时点验证，再研究回测与模型。
