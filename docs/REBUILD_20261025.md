## 选择成熟实现，而不是给规则换名字

比较了[Quanti](https://github.com/coo-moon/quanti)、[Microsoft Qlib](https://github.com/microsoft/qlib)和当前已使用的[ta](https://github.com/bukosabino/ta)。Qlib是模型研究工作流，无法用星数证明选股收益或开箱适配本地GUI；本次实际选用Quanti的两个独立选股算法和ta技术指标库，构建本地研究终端。没有声称“全网第一”、训练AI模型或证明收益。

Quanti完整源码成功通过codeload下载；重点逐行审查两份筛选器、基类、BarData模型及数据Provider的复权边界。只引入两个纯计算筛选器，替换导入依赖，保留上游算法和MIT许可证。没有接入其交易、Agent和订单模块。来源和文件摘要见[NOTICE](../app/vendor/quanti/NOTICE.md)。本次是目标文件审查，不是上游全量审计。

## 新首页

- `/`：新研究终端，三栏展示股票池、个股曲线和开源选股结果；支持名称/代码搜索、自选列表、历史日期、60/120期/全历史切换、图表悬停查看数值。
- `app/engines.py`：Quanti MA5>MA20>MA60与RSI超卖直接复用；本地MACD金叉组合和20期收盘放量突破。分数表示算法内命中强度，不能解释为概率或跨算法比较。
- 图表使用ta 0.11.0的MA、MACD、Wilder RSI、布林带；预热数据为null，不填零冒充真实指标。原行情只保存收盘价，明确展示收盘曲线，不编造OHLC蜡烛。
- 每日笔记复用原复盘表，重启保留；切换日期/算法保留本页未保存草稿，关闭含草稿页面会提示。
- 原持仓和配置页面在`/classic`；新首页开源引擎与旧工作台配置独立，旧页面扫描采用其已保存策略。点击“扫描市场初筛”使用旧工作台配置获取候选池，再在新首页按所选算法筛选缓存池，并非按新引擎遍历全部A股。

## 真实数据与CSV

保留BaoStock和腾讯备用线路。自选股票会合并到手动更新池，含持仓共最多50只。免费接口的稳定性不是本程序能保证的，失败保留缓存、不切换假数据。

本地CSV支持UTF-8列：`code,name,day,close,amount`。代码六位或sh./sz.形式；日期ISO；收盘价为不复权人民币价格，成交额单位元。文件最多2MB/20000行/50只/370天，只允许早于今天的数据。所有行通过校验才事务替换当前来源缓存；用户必须勾选替换确认。**不是合并导入**，操作前备份停止服务后的data/stock.sqlite3。

CSV来源标记为local_csv，ST/停牌状态设为未知，不将手工文件当作核验成功的可交易行情；清空旧指数，避免混搭市场判断；保留持仓、策略、复盘笔记和历史报告。再次联网更新会重新取得完整数据，不增量拼接CSV到供应商历史。

## 新API

| 接口 | 功能 |
|---|---|
| GET /api/engines | 实际算法和来源 |
| GET /api/engine-screen?engine=quanti_ma&day=YYYY-MM-DD | 截止日缓存选股，缺省最新日 |
| GET /api/instruments | 各股票最后缓存价 |
| GET /api/series/{code}?day=YYYY-MM-DD | 收盘和指标历史 |
| GET/PUT /api/watchlist | 读取/加入自选 |
| DELETE /api/watchlist/{code} | 移除自选 |
| POST /api/import-csv | JSON text与replace_cache:true |

历史图表和选股只读取截至日期数据；当天缺行情股票不进入当日选股。模拟模式明确标记，不能导入真实CSV或更新网络数据。没有自动委托接口。
